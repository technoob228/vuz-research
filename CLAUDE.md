# Контекст репозитория

Ресерч для выбора бакалавриата (поступление 2026): сравнение шести программ РЭУ им. Плеханова по учебным планам и преподавателям + таблица вариантов по другим вузам. Подробности — в README.md.

## Структура

- `index.html` — дашборд сравнения шести программ РЭУ. Vanilla HTML+SVG+JS, без зависимостей и сборки. Все данные захардкожены в `<script>` внизу файла (константы PROGS, PROFILE, NUMS, FACULTY и т.д.).
- `uchplan-bsa.html` — дашборд одного плана (БСА), устроен так же.
- `data/programs.json` — те же данные, что в index.html, в JSON (автоматически извлечены из констант). Если меняешь данные — меняй в обоих местах или пересобери JSON.
- `data/вузы.csv` — таблица вариантов, разделитель `;`, кодировка UTF-8. Колонка «мой балл» — сумма ЕГЭ под конкретный набор предметов программы.
- `plans/*.pdf` — учебные планы РЭУ. Это сканы БЕЗ текстового слоя: pdftotext вернёт пустоту, парсить можно только через OCR или визуально.

## Правила

- Дашборды должны оставаться одним самодостаточным файлом: никаких npm, CDN и внешних шрифтов — их открывают двойным кликом.
- Тёмная тема уже есть (CSS-переменные + data-theme на html) — при добавлении элементов используй существующие переменные (--surface-1, --text-primary, --s1..--s7), не хардкодь цвета.
- Цифры из учебных планов выверены с точностью до часа — не менять без сверки с PDF. Цены и проходные баллы — по приёму 2025/26, могут устаревать.
- Часы в тематическом профиле (PROFILE) — авторская классификация дисциплин по категориям; суммы должны сходиться с итогами блока Б1 плана.
